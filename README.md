# 1. Reverse a String using Stack

## Description
This program uses a stack to reverse a given string.

## Algorithm
1. Read the string.
2. Push each character into the stack.
3. Pop characters from the stack.
4. Display the reversed string.

## Output
```text
Enter a string: HELLO
Reversed String: OLLEH
```

# 2. Balanced Parentheses

## Description
This program checks whether the given expression has balanced parentheses.

## Algorithm
1. Read the expression.
2. Push opening brackets into stack.
3. Pop when closing brackets occur.
4. Check matching brackets.
5. Display result.

## Output
```text
Enter Expression: (A+B)*(C-D)
Balanced Expression
```

# 3. Next Greater Element

## Description
This program finds the next greater element for every element in the array.

## Algorithm
1. Read array elements.
2. Compare each element with next elements.
3. Print first greater element.
4. If not found, print -1.

## Output
```text
Enter Number of Elements: 5
Enter Elements: 4 5 2 10 8

4 --> 5
5 --> 10
2 --> 10
10 --> -1
8 --> -1
```
